# Sistema de Drivers de Impresoras 3D - RepuestosYa\n\n> ⚡ Arquitectura escalable, agnóstica de marca, con soporte multi-protocolo y bidireccional\n\n## 🎯 Objetivo\n\nSoportar múltiples marcas de impresoras (Bambu Lab, Creality/Klipper, etc.) sin condicionales en el código principal. Cada driver es independiente, testeable y puede ser implementado sin cambiar el resto del sistema.\n\n---\n\n## 📦 Componentes\n\n### 1. `BasePrinterDriver` (Abstract)\nClase base que define el contrato para cualquier driver.\n\n```javascript\nclass BasePrinterDriver {\n  async connect()\n  async disconnect()\n  async uploadAndPrint(filePath, fileName)\n  async pause()\n  async resume()\n  async stop()\n  async startCamera(callback)\n  async stopCamera()\n  getNormalizedTelemetry()\n}\n```\n\n### 2. `BambuDriver` ✅\nImplementación completa para Bambu Lab (A1, P1, X1).\n\n**Features**:\n- MQTT 3.1.1 con keepalive 10s\n- Polling activo `pushall` cada 3s\n- Stateful telemetry merging (no pierde datos)\n- FTPS upload (puerto 990)\n- Cámara (puerto 6000, placeholder)\n\n**Config**:\n```javascript\n{\n  id: \"uuid\",\n  name: \"A1 Mini\",\n  ip: \"192.168.0.100\",\n  protocol: \"bambu_lan\",\n  credentials: {\n    access_code: \"4E5A4F36\",\n    serial_number: \"0M11PC250134E9CE\",\n    model: \"A1\"\n  }\n}\n```\n\n### 3. `PrinterFarmManager`\nGestor central que coordina múltiples drivers.\n\n```javascript\nfarmManager.connectPrinter(config)      // Crear driver\nfarmManager.disconnectPrinter(id)       // Destruir driver\nfarmManager.executeCommand(id, cmd)     // Enviar comando\nfarmManager.getStatus()                 // Estado global\n```\n\n### 4. `TransportLayer`\nComunicación dual: IPC local + Realtime Broadcast.\n\n```\n┌─────────────────────────┐\n│  PrinterFarmManager     │\n│  (telemetría fluye)     │\n└──────────────┬──────────┘\n               │\n         TransportLayer\n        /              \\\n    IPC Local       Realtime Broadcast\n    (<100ms)        (100-500ms)\n      │               │\n    React           Supabase\n  (UI tiempo     (otros agentes,\n   real)         persistencia)\n```\n\n---\n\n## 🔄 Flujos de Datos\n\n### Telemetría\n```\nImpresora MQTT\n    ↓ (cada TransportLayer.handleTelemetryFromFarm\n├─────────────────────────────────────┤\n│ 1.
